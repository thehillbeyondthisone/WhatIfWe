# 🗺️ What if we… — Product Roadmap

## 🎯 Vision
Create the ultimate couples' date planning app that makes discovering, organizing, and choosing date ideas effortless and fun.

---

## ✅ Phase 0: MVP (COMPLETE)
**Status:** SHIPPED  
**Focus:** Core functionality for two users on local network

### Completed Features
- ✅ Dark, professional UI with gradient backgrounds
- ✅ Individual rating system (1-5 stars)
- ✅ Tag system with filtering
- ✅ Search by description and tags
- ✅ Multiple sort options
- ✅ YouTube thumbnail auto-fetch
- ✅ Import/Export JSON
- ✅ Local network sync
- ✅ Mobile responsive design

---

## 🚀 Phase 1: Enhanced Experience (IN PROGRESS)
**Timeline:** 1-2 weeks  
**Focus:** Polish, UX improvements, and media handling

### 1.1 Media & Thumbnails ⭐ PRIORITY
- [x] **Image upload** - Drag & drop or click to upload (base64 storage)
- [x] **Thumbnail preview** in form
- [ ] **Reddit video support** - Extract thumbnails from Reddit posts
- [ ] **Vimeo support** - Auto-fetch Vimeo thumbnails
- [ ] **TikTok support** - Handle TikTok video links
- [ ] **Instagram support** - Handle Instagram posts
- [ ] **Direct video URLs** - Extract first frame as thumbnail
- [ ] **Image compression** - Optimize uploaded images automatically
- [ ] **Multiple images** - Gallery support per idea

### 1.2 Quality of Life Improvements
- [x] **Match badges** - Visual indicator when both rated 3+ stars
- [x] **Average rating display** on cards
- [x] **Date added/modified** timestamps
- [x] **Click star again to clear** rating (set to 0)
- [x] **Keyboard shortcuts** - Esc to close modals
- [x] **Toast notifications** for actions
- [x] **Loading states** - Spinners during save/load
- [x] **Duplicate idea** button
- [ ] **Undo delete** - 5-second grace period
- [ ] **Bulk actions** - Select multiple, bulk delete/tag
- [ ] **Quick rate** - Swipe gestures on mobile
- [ ] **Hover previews** - Show video preview on hover
- [ ] **Keyboard navigation** - Arrow keys through cards

### 1.3 Organization & Discovery
- [ ] **Custom partner names** - Set in UI (not code)
- [ ] **Color-coded tags** - Assign colors to tag categories
- [ ] **Tag management** - Rename, merge, delete unused tags
- [ ] **Saved filters** - Save favorite filter combinations
- [ ] **Smart suggestions** - "Similar ideas" based on tags/ratings
- [ ] **Recently viewed** - Track last 10 opened ideas

## 💫 Phase 2: Rich Features (4-6 weeks)
**Focus:** Notes, history, favorites, and enhanced organization

### 2.1 Notes & Communication
- [ ] **Per-idea notes** - Text notes from each partner
- [ ] **Note timestamps** - Show when notes were added
- [ ] **Reactions** - Quick emoji reactions to notes
- [ ] **Attachments** - Link external docs or images to ideas
- [ ] **Voice notes** - Record audio thoughts (base64)

### 2.2 Status & Tracking
- [ ] **Status field** - New, Planning, Scheduled, Done, Archived
- [ ] **"Done" marker** - Mark ideas as completed
- [ ] **Date completed** - Track when you did the date
- [ ] **Favorite/Pin** - Star important ideas to top
- [ ] **Custom fields** - Cost estimate, duration, location
- [ ] **Progress tracker** - % of ideas completed per month

### 2.3 Calendar & Planning
- [ ] **Calendar view** - Monthly calendar showing scheduled dates
- [ ] **Schedule dates** - Assign dates to calendar
- [ ] **Recurring ideas** - "Movie night every Friday"
- [ ] **Weather integration** - Flag outdoor ideas based on forecast
- [ ] **Time of day** - Morning, afternoon, evening, night tags
- [ ] **Season tags** - Summer, winter, etc. for seasonal ideas

### 2.4 Analytics & Insights
- [ ] **Stats dashboard** - Total ideas, completed, average ratings
- [ ] **Rating history** - See how ratings changed over time
- [ ] **Tag cloud** - Visual representation of most-used tags
- [ ] **Compatibility score** - % of ideas you both love
- [ ] **Date frequency** - How often you do date nights
- [ ] **Favorite categories** - Most-loved types of dates

---

## 🌟 Phase 3: Advanced Features (8-12 weeks)
**Focus:** Collaboration, reminders, and smart features

### 3.1 Smart Recommendations
- [ ] **AI suggestions** - GPT-4 suggests ideas based on your history
- [ ] **Seasonal prompts** - "Try these fall activities"
- [ ] **Nearby events** - Integration with local event APIs
- [ ] **Budget-aware** - Filter by price point
- [ ] **Time-aware** - Suggest quick ideas when busy
- [ ] **Mood-based** - "Feeling adventurous?" filter

### 3.2 Notifications & Reminders
- [ ] **Browser notifications** - Remind about scheduled dates
- [ ] **Weekly digest** - Email with top-rated unscheduled ideas
- [ ] **Anniversary reminders** - Special date suggestions
- [ ] **Idea expiration** - "This event ends soon!"
- [ ] **New idea alerts** - Notify when partner adds idea

### 3.3 Collaboration Features
- [ ] **Comments on ideas** - Reply threads
- [ ] **Vote system** - Upvote/downvote instead of just stars
- [ ] **Proposal system** - "Let's do this Saturday?"
- [ ] **Decision mode** - Tinder-style swipe to agree
- [ ] **Date planning chat** - Mini chat per idea
- [ ] **Activity log** - See who changed what when

### 3.4 Enhanced Media
- [ ] **Video playback** - Embed YouTube/Vimeo players
- [ ] **Photo gallery** - Upload multiple photos per idea
- [ ] **Before/After** - Upload photos from completed dates
- [ ] **Location maps** - Embedded Google Maps
- [ ] **Spotify integration** - Link playlists to date ideas

## 🛠️ Technical Debt & Infrastructure

### Performance
- [ ] **Database migration** - Move from JSON to SQLite/PostgreSQL
- [ ] **Image CDN** - Cloudflare for image delivery
- [ ] **Caching** - Redis for faster loads
- [ ] **Lazy loading** - Load images as needed
- [ ] **Code splitting** - Faster initial load

### Security
- [ ] **Authentication** - Secure login system
- [ ] **Authorization** - Fine-grained permissions
- [ ] **HTTPS** - SSL certificates
- [ ] **Rate limiting** - Prevent abuse
- [ ] **Input sanitization** - XSS protection
- [ ] **CSRF tokens** - Secure forms

### DevOps
- [ ] **CI/CD pipeline** - Automated deployments
- [ ] **Automated tests** - Unit, integration, E2E
- [ ] **Monitoring** - Error tracking (Sentry)
- [ ] **Analytics** - Usage stats (privacy-friendly)
- [ ] **Backup system** - Automated daily backups
- [ ] **Docker** - Containerized deployment
